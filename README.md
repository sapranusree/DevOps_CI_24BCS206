# Cinema Ticket Booking and Seat Allocation System

## Project Name

DevOps_CI_24BCS206

## Description

This project is a simple Cinema Ticket Booking and Seat Allocation System developed using Python.

The system provides functionality for viewing movies and shows, displaying available seats, allocating seats, preventing duplicate bookings, cancelling bookings, calculating ticket costs, and confirming bookings.

## Core Features

- View available movies
- View movie show timings
- Display cinema seats
- Display available seats
- Check seat availability
- Allocate seats
- Prevent duplicate seat bookings
- Cancel bookings
- Calculate ticket cost
- Confirm bookings
